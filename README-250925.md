# Gender Attribution and PCA Pipeline - 25/09/25

## Quick Start for Gender Analysis on Gemma-2-2b

### 1. Run Gender Attribution
```bash
./scripts/sae_attribution_gender_gemma.sh
```
- Computes SAE attribution for gender dataset
- Outputs to `/root/sae-attributions/gender.pt`

### 2. Cache Gender SAE Features
```bash
./scripts/cache_gender_gemma_sae.sh
```
- Caches the gender SAE attribution results
- Saves to `/workspace/sae_caches/gender_cache`

### 3. Train Gender Model (if needed)
```bash
./scripts/train_gender_pca.sh --type base
```
- Trains gender model on Gemma-2-2b
- Saves to `/root/gender_gemma`

### 4. Create PCAs from Trained Model
```bash
./scripts/make_gender_gemma_pca.sh
```
- Creates PCAs comparing trained vs base model
- Outputs to `/root/pcas/gender_gemma.pt`

### 5. Cache Gender PCA Features
```bash
./scripts/cache_gender_gemma_pca.sh
```
- Caches the PCA features
- Saves to `/workspace/pca_caches/gender_cache`

### 6. Explain Gender SAE Features
```bash
./scripts/explain_gender_gemma_sae.sh
```
- Generates explanations for gender SAE features
- Outputs to `/root/gender_sae_explanations`

### 7. Explain Gender PCA Features
```bash
./scripts/explain_gender_gemma_pca.sh
```
- Generates explanations for gender PCA features
- Outputs to `/root/gender_pca_explanations`

### 8. Create Gender SAE Intervention
```bash
python /root/steering-finetuning/finding_features/make_gender_sae_intervention.py
```
- Extracts high-scoring SAE features (score >= 70)
- Creates intervention vectors using QR decomposition
- Outputs to `/workspace/gender_interventions/gender_sae_intervention.pt`

### 9. Create Gender PCA Intervention
```bash
python /root/steering-finetuning/finding_features/make_gender_pca_intervention.py
```
- Extracts high-scoring PCA components (score >= 70)
- Creates intervention vectors from selected PCs
- Outputs to `/workspace/gender_interventions/gender_pca_intervention.pt`

### 10. Train with SAE Interventions
```bash
./scripts/train_gender_sae_intervention.sh
```
- Trains models with SAE interventions across seeds 0-4
- Saves to `/root/gender_sae_trained_s{seed}`

### 11. Train with PCA Interventions
```bash
./scripts/train_gender_pca_intervention.sh
```
- Trains models with PCA interventions across seeds 0-4
- Saves to `/root/gender_pca_trained_s{seed}`
